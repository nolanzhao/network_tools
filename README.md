#### 仅供学习研究, 请勿用于非法用途


## server

ubuntu 24.04 lts, root

#### 1. vless + reality
最稳定, TCP

无需个人域名
```
./install_vless_reality.sh
```

#### 2. tuic
速度快, QUIC 协议, UDP

安装过程需填写个人域名和邮箱

```
./install-tuic-server.sh
```

#### 3. hysteria2 (推荐)
速度最快, QUIC 协议, UDP

安装后需修改配置文件, 填写个人域名和邮箱

https://v2.hysteria.network/zh/docs/getting-started/Installation/
